General Comments:
- Henrik, for the CO2 molecule, it looks like your code defines bond lengths starting from atom 0 to atom N sequentially. But in case of CO2, since you have atom 0 as carbon, atom 1 as oxygen and atom 3 as oxygen, your bond lengths are between oxygen-carbon and oxygen-oxygen. But oxygens are not connected in CO2. In these cases make sure you go from left to right while numbering atoms under #atomic positions in a linear molecule.

- Add RotationProbability for all simulations except Widom insertion simaultions 

- remove repetitive parameters from force_field_mixing_rules that are not TraPPE

- Component 0 should be on the same line as the molecule name 

- Molecule name should have no spaces 

- Set number of initialization cycles to 0 for Widom insertions 

- Don't calculate Rosenbluth weight for molecule with no torsions 

- In NVT ensemble, no need to mention "ExternalPressure 0".
