HENRY COEFFICIENT CALCULATION FOR N-HEXANE AND PENTANE ON IRMOF-13
==================================================================

OBJECTIVE:
Determine the Henry coefficients of n-hexane and pentane on IRMOF-13 framework
Given: Helium void fraction = 0.877

SIMULATION SETUP STEPS:

1. FRAMEWORK AND MOLECULE PREPARATION:
   - Loaded IRMOF-13 framework (framework.cif)
   - Generated molecule definitions for n-hexane and pentane (.def files)
   - Generated force field parameters (force_field_mixing_rules.def, pseudo_atoms.def)
   - Framework unit cells: [2, 2, 1] (optimized for 12.8 Å cutoff)

2. TWO-STEP SIMULATION PROCESS REQUIRED:

   STEP 1: PREREQUISITE - IDEAL GAS ROSENBLUTH WEIGHT CALCULATION
   - File: simulation_1/simulation.input
   - Purpose: Calculate IdealGasRosenbluthWeight for both molecules at 298K
   - Setup: Box simulation (30x30x30 Å) with 1 molecule each
   - Cycles: 100 initialization + 500 production (reduced from typical 1000/5000)
   - Monte Carlo moves: Translation, Rotation, Reinsertion
   - MUST BE RUN FIRST!

   STEP 2: MAIN HENRY COEFFICIENT CALCULATION
   - File: henry_coefficient.input
   - Purpose: Calculate Henry coefficients using Widom insertion
   - Setup: IRMOF-13 framework with helium void fraction 0.877
   - Unit cells: 2×2×1 (optimized for cutoff)
   - Cycles: 100 initialization + 500 production (accelerated)
   - CreateNumberOfMolecules: 0 (no actual insertion, only probe moves)
   - WidomProbability: 1.0 (essential for Henry coefficient)
   - Requires IdealGasRosenbluthWeight values from Step 1

3. EXECUTION SEQUENCE:
   a) Run simulation_1/simulation.input first to get Rosenbluth weights
   b) Extract IdealGasRosenbluthWeight values from output
   c) Update henry_coefficient.input with correct Rosenbluth weights
   d) Run henry_coefficient.input for final Henry coefficients

4. EXPECTED OUTPUT:
   - Henry coefficients in [mol/kg/Pa] units
   - Separate values for n-hexane and pentane
   - Statistical uncertainties and error estimates

IMPORTANT NOTES:
- Simulation cycles reduced to 1/10 of typical values for speed
- Maximum 8 molecules limit respected (using 0 for main simulation)
- Temperature: 298K for both simulations
- Framework void fraction: 0.877 (given)
- Both components calculated simultaneously in main simulation
- Molecule names: 'n-hexane' and 'pentane' (as generated by system)
