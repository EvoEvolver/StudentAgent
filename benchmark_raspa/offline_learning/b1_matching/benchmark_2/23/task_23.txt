Henry coefficient calculation in RASPA requires a two-step process: 1) First calculate IdealGasRosenbluthWeight for each molecule using Widom insertion in an empty box, 2) Then use those values in the main Henry coefficient simulation with the framework. The IdealGasRosenbluthWeight simulation uses MonteCarlo with WidomProbability 1.0, CreateNumberOfMolecules 0, in a 30x30x30 Angstrom empty box. The main Henry coefficient simulation uses Widom insertion with the calculated IdealGasRosenbluthWeight values and the framework with given helium void fraction.
