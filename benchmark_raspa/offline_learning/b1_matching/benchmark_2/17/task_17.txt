Helium void fraction calculation in RASPA: Uses MonteCarlo simulation with Widom insertions of helium on framework. This is a prerequisite simulation for other framework studies. Key requirements: Framework configuration (not Box), unit cells >2×cutoff (>24Å for 12Å cutoff), WidomProbability=1.0, helium as probe molecule. Result is accessible void space fraction (0-1 range). Pore volume = void fraction × unit cell volume. This value is required for subsequent GCMC adsorption simulations. For IRMOF-13: need proper framework file and unit cell dimensions meeting cutoff requirements.
RASPA behavior: When a simulation fails, RASPA automatically creates a new empty working directory (simulation_N+1). All input files (framework.cif, molecule.def files, force field files) must be regenerated in the new directory before running the simulation again. This is why 'Cannot open .def file' errors occur - the files exist in previous simulation directories but not in the current one.
