To calculate ideal Rosenbluth weights for n-hexane in RASPA: 1) Load n-hexane molecule using Molecule loader tool, 2) Create simulation input file with MonteCarlo simulation type, empty box (30x30x30 Angstrom), WidomProbability 1.0, CreateNumberOfMolecules 0, temperature 298K, pressure 1e5 Pa, 100000 cycles with 10000 initialization cycles. This is a prerequisite simulation that must be run before GCMC simulations to get the IdealGasRosenbluthWeight parameter.
