For RASPA adsorption enthalpy calculations: Use Grand Canonical Monte Carlo (GCMC) simulation with SwapProbability 1.0. Required prerequisites are HeliumVoidFraction (calculated separately) and IdealGasRosenbluthWeight for each component (temperature-dependent). Use Framework keyword for porous materials. Specify list of increasing pressures for isotherms. Framework unit cells must have perpendicular lengths > 2×cutoff (>24Å for default 12Å cutoff). Enthalpy of adsorption calculated using fluctuation formulas with error bars. For comparing different molecules, use same framework and simulation conditions.
For GCMC adsorption enthalpy simulations in RASPA: Use SwapProbability 1.0 for particle insertion/deletion moves. Typical cycle counts are 500,000 cycles with ~1,000 initialization cycles. Properties to compute include adsorption isotherms, enthalpy of adsorption, energy histograms, number of molecules histograms. ComputeMoleculeProperties must be 'yes'. Monitor that swap addition and deletion moves have similar acceptance numbers for good performance.
